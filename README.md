## **Frontend Guidelines **

### Regras de Código para Frontend

1. **Sempre usar Framework:**
   Nada de JavaScript puro sem motivo. Use React, Vue ou outro framework para deixar tudo organizado e moderno.

2. **Validação Antes do Envio:**
   Cheque os dados do usuário antes de enviar pro backend. Prevenir é melhor que chorar depois.

3. **Validador do Framework:**
   O framework tem ferramentas de validação prontas? Use! Evite reinventar a roda.

4. **Segurança dos Dados:**
   Dados malucos ou maliciosos não são bem-vindos. Filtre e verifique antes de salvar ou mostrar.

5. **Evitar Redundância:**
   Repita menos, reaproveite mais. Componentes, funções e classes são seus amigos.

6. **Nomes em Inglês:**
   Variáveis, funções e componentes em inglês deixam o código mais padrão e fácil de entender.

7. **Valores Repetitivos:**
   Endpoints, tokens e valores que se repetem? Use variáveis ou variáveis de ambiente. Organização é tudo.

8. **Documentação:**
   Comentários e DocBlocks ajudam você e outros devs a entenderem seu código sem dor de cabeça.

9. **Código Limpo e Legível:**
   Indentação correta, nomes claros e comentários úteis fazem toda a diferença.

10. **Commits Claros:**
    Mensagens de commit tipo “arrumei coisas” não ajudam ninguém. Seja claro e específico.
